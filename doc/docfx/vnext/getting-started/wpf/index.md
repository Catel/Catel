---
title: "Getting started with WPF" 
---
Welcome to the *Getting started* guide for Catel and WPF. In this guide, a simple application will be created with the most commonly used aspects of Catel and WPF.

The application will manage persons and allow the user to add, edit, and remove them.

Note that this guide assumes that the reader has a basic understanding of XAML and WPF since this guide will not cover these basics.

The complete source code for this example can be found at <https://github.com/Catel/Catel.Examples/tree/master/src/Catel.Examples.WPF.PersonApplication>.
